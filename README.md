# 🎓 UCfERI Website

**University of Venda Centre for Entrepreneurship and Rapid Incubation (UCfERI)**

A static informational website for the UCfERI entrepreneurship centre at the University of Venda, Thohoyandou, South Africa.

## 📋 Overview

This website serves as the digital presence for UCfERI, showcasing their entrepreneurship programs, business incubation services, student network (CEEIIC), events, success stories, and resources for aspiring entrepreneurs in the Vhembe district.

## 🚀 Live Site

**URL:** [https://tshifhungucodes.github.io/UCFERI_WEBSITE/](https://tshifhungucodes.github.io/UCFERI_WEBSITE/)

## 🔧 Local Development

This is a static HTML/CSS/JS site with no build tools required. To run locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/TshifhunguCodes/UCFERI_WEBSITE.git
   ```

2. Open any `.html` file in your browser, or use a local server:
   ```bash
   npx serve .
   ```

## 🌐 Deployment

The site is deployed via **GitHub Pages** from the `main` branch. Push to the remote repository to trigger automatic deployment.
